# 交付中心

本目录是 AI 协作标准库的统一交付入口，用于接收、审核和归档 Gemini、ChatGPT 或其他协作工具产生的项目交付物。

## 目录结构

```text
DELIVERY/
├── README.md
├── INBOX/
│   ├── README.md
│   └── 待交付/
│       └── README.md
└── ARCHIVE/
    └── README.md
```

## 标准流转

1. **接收：** 将尚未审核的交付包放入 `INBOX/待交付/`。
2. **登记：** 保留交付包原始文件名，并在交付说明中标明任务编号、版本和交付日期。
3. **审核：** ChatGPT GPT 根据任务书、验收标准和实际交付内容进行独立审核；不得仅凭交付者自述判定通过。
4. **处理：** 如有问题，退回修改并保留必要的审核记录；不得把未通过的成果标记为正式归档。
5. **归档：** 只有在审核完成且用户明确确认后，才将最终成果及相关记录移入 `ARCHIVE/`。

## 管理原则

- 原始交付包应保留，不直接覆盖或静默修改。
- 未经用户确认，不删除原始交付物，不擅自改变项目文件。
- 每次交付应能追溯到任务编号、交付版本、审核结论和用户确认状态。
- Commit SHA 仅在确实完成 Git 提交时记录；没有提交就标注“未提交”。
- 本目录是通用交付区。具体项目如有更严格的交付规则，以该项目已确认规则为准。
