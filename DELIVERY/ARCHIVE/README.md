# 已确认归档区

本目录只存放已经完成独立审核，并经用户明确确认可以归档的交付成果及其必要记录。

## 归档条件

归档前必须确认：

- 对应任务书和验收范围明确。
- 已完成交付内容检查及必要的测试/证据核验。
- GPT 已给出明确审核结论，问题项已处理或由用户明确接受。
- 用户已明确确认归档。
- 文件来源、版本和处理记录可追溯。

## 建议归档结构

```text
ARCHIVE/
└── ACS-0001/
    ├── 交付包.zip
    └── 归档记录.md
```

## 归档记录至少包含

| 字段 | 内容 |
|---|---|
| 任务编号 | 例如 ACS-0001 |
| 任务名称 | 本轮任务名称 |
| 交付版本 | 交付包版本 |
| 交付日期 | 实际收到日期 |
| 审核结论 | 通过 / 有条件通过 / 未通过 |
| 用户确认 | 已确认 / 未确认 |
| 归档日期 | 实际归档日期 |
| Commit SHA | 如已提交则填写；否则写“未提交” |
| 备注 | 遗留问题、例外批准或其他说明 |

## 管理原则

- 未经用户确认，不得将交付物标记为正式归档。
- 不得伪造审核结果、测试结果、用户确认或 Commit SHA。
- 保留必要的原始交付包和审核记录，确保后续可以追溯。
