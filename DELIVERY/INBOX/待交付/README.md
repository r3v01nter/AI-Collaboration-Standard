# 待交付文件投放区

将 Gemini 或其他 AI 完成的交付包放在本目录，等待 ChatGPT GPT 独立审核。

## 当前交付要求

对于 ACS-0001 等明确要求单一 ZIP 交付的任务：

- 最终只放置一个完整 ZIP 交付包。
- ZIP 内应保留目标仓库相对路径和完整目录结构。
- ZIP 应包含所有新增/修改文件、交付报告、自检结果及未完成事项说明。
- 不要把 ZIP 拆成多个文件分别投放，除非对应任务书明确允许。
- 不要在此处直接解压并覆盖仓库现有文件。

## 命名建议

`任务编号_任务简称_版本_交付日期.zip`

例如：

`ACS-0001_AI协作标准库整理与完善_V1.0_2026-11-27.zip`

## 审核前检查

投放前确认：

1. 文件可以正常打开或解压。
2. ZIP 内目录结构完整。
3. 包含交付说明、测试/自检结果和未完成事项。
4. 未将未经授权的敏感信息或凭据打包。
5. 原始交付包保持完整，不要自行改写其内容。

**注意：** 文件放入本目录仅代表已接收，不代表审核通过、用户验收通过或已合并进仓库。
